### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.13
- Раздел Customize теперь доступен всем: в одном месте можно управлять подключаемыми модулями, навыками, MCP-серверами и холстами, а также создавать, редактировать и удалять личные навыки.
- В обзорах запросов на вытягивание теперь отображаются связанные закрывающие задачи, их можно редактировать, а связывать запросы с задачами можно из меню заголовка.
- Автоматизация сеансов теперь включена по умолчанию, поэтому запланированные запросы запускаются без отдельного включения функции.

### GitHub Copilot App - v1.1.14
- Выбор модели, уровня рассуждений и контекстного окна объединен в одно меню в поле сообщения.
- Agent Merge больше не считает проверки запросов на вытягивание полностью завершенными после просмотра только первой страницы комментариев.
- Ошибки загрузки навыков теперь показываются как нейтральные закрываемые уведомления, не заменяя весь список навыков.

### GitHub Copilot CLI - 1.0.81
- Панель подключаемых модулей теперь доступна всем для управления модулями, навыками и MCP-серверами; установленные ресурсы предлагают обновления из источника.
- Добавлена поддержка MCP 2026-07-28 в CLI, SDK, IDE и клиентах в памяти.
- Добавлена поддержка уровня рассуждений xhigh для Grok 4.6 и модели Gemini 3.7 Flash.
- При запуске можно восстановить сеансы, которые были открыты при завершении CLI, а команда `copilot app` открывает приложение GitHub Copilot в текущем каталоге.
- Добавлены параметры `defaultMode` и `defaultPermissionMode` для новых интерактивных сеансов; автоматический режим теперь адаптирует выбор модели по мере развития задачи.
- Клиенты ACP теперь получают идентификаторы субагентов и обновления их заголовка, режима, команды и плана в реальном времени.

### GitHub Copilot CLI - 1.0.82
- Нажатие Ctrl+E разворачивает карточку подтверждения плана и снова показывает план целиком.

### Visual Studio Code - 1.135
- В списке сеансов VS Code можно продолжить недавние сеансы агентов Copilot или Claude, созданные в других приложениях.
- Agent Host подключает один сеанс агента к нескольким окнам VS Code; агент Copilot работает на базе Copilot SDK.
- Экспериментальная функция Rubber Duck запрашивает второе мнение у дополнительной модели, помогая находить упущенные детали и крайние случаи.
- В окне Agents появился упрощенный боковой интерфейс с более понятными элементами управления сеансом и статусами изменений, запросов на вытягивание, задач, браузера и артефактов.
- В нижнем колонтитуле ответа чата отображается разбивка по моделям: входные, кэшированные входные и выходные токены для каждого хода.
