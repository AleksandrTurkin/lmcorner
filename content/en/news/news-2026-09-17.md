### Greetings, human 🤖

### GitHub Copilot App - v1.1.20
- Generated Markdown artifacts now open in the Files tab alongside repository files, with a switcher and an option to promote an artifact into the repository.
- Custom agents with the same display name across plugins are now distinguished by their owning plugin.
- The "Start from scratch" option in session creation menus and project pickers is now called "Chat".
- Fixed Cloud session responses sometimes stopping early and dropping later message content.

### GitHub Copilot App - v1.1.21
- Generated Markdown files now open in the Files tab alongside repository files, with a source switcher and an option to promote an artifact into the repository.
- Custom agents with duplicate display names are now labeled with their owning plugin.
- Fixed finishing a background session sometimes pulling you away from the session or grid you had selected.
- Long or multiline answers to ask-user prompts now retain their full content and original line breaks.

### GitHub Copilot CLI - 1.0.85
- Added `/settings` options to opt in to context management tools for agents and subagents.
- Added support for the GPT-6 Astra model.
- Added session and memory import commands for the semantic JSONL interchange format.
- Plugin-contributed agents discovered by the CLI can now be selected and run.
- Subagent launches now honor explicit model, reasoning-effort, and context-tier preferences from applicable global and custom instructions.

### Visual Studio Code - 1.138
- Automations are now enabled by default and can be exported and imported to share agent workflows.
- Agent sessions can run in local Dev Containers using the project's tools and dependencies.
- Expanded Codex support in Agent Host lets users continue sessions across ChatGPT and VS Code, switch between Copilot and ChatGPT subscriptions, and use VS Code tools.
- Agent Host sessions can create pull requests through a form for reviewing and editing generated titles, descriptions, draft status, and merge options.
- Completed agent sessions can be marked as done automatically after their pull requests merge and optionally deleted after a grace period.
- The unified workspace and repository picker lets users start agent work from local folders, GitHub repositories, cloud repositories, and remote targets.
