### Greetings, human 🤖

### GitHub Copilot CLI - 1.0.79
- The model picker now groups models into Recent, Recommended, New, and other sections, with Shift+Tab switching between grouping views.
- Added support for the kimi-k3 model.
- `--plan` can now be combined with `--mode autopilot` to plan first and then implement without waiting for approval.
- Agent Plugins can ship extensions under a `com.github.copilot/extensions/` directory, and custom agents honor deferred tool loading.
- The Sessions tab and sidebar can manage multiple concurrent sessions, while `/tasks` navigation provides nested task browsing and a steerable live timeline.
- `/model` is now session-scoped by default, while `/config model` sets defaults for future sessions.
- The `/app` command opens the current session in the GitHub Copilot desktop app.

### Visual Studio 2022 - 17.14.38
- Fixed a Copilot Chat query failure caused by accessing a disposed service object.

### Visual Studio 2026 - August Update 18.9.0
- Supported models now offer low, medium, and high thinking-effort controls so you can balance response quality and token usage.
- The Git agent can review uncommitted changes and commits, displaying Copilot comments inline in the editor.
- Organization owners can publish custom agents for everyone in the organization, and Visual Studio shows them in the agent picker.
- Copilot plan usage is available directly from the context window, with clearer notifications as limits approach.
- The redesigned model picker and management view support pinning favorite models, collapsing others, and viewing model costs, capabilities, and context-window sizes.
