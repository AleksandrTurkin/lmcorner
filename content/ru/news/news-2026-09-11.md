### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.16
- Новые сеансы теперь по умолчанию используют GPT-5.6 Sol со средним уровнем рассуждений, а выбор модели, уровня рассуждений и контекстного окна объединен в один элемент управления.
- Добавлена команда `/settings` для открытия настроек приложения прямо из поля сообщения.

### GitHub Copilot App - v1.1.17
- В панели Goal теперь отображаются текущий статус и подробности: цель, итог выполнения, причина паузы, число ходов и расход AI Credits.
- Для сеансов, созданных из проектов и автономной работы, используется единый интерфейс создания и навигации.

### GitHub Copilot App - v1.1.18
- В кнопках исправления запросов на вытягивание появился вариант «Исправить с инструкциями», позволяющий добавить указания перед запуском исправления.
- В описаниях уровней Efficiency, Balance и Intelligence в выборе автоматической модели уточнены различия между режимами.
- Исправлена ошибка, из-за которой режим Agency и связанные параметры могли оставаться отключенными после включения.

### GitHub Copilot App - v1.1.19
- Исправлена ошибка, из-за которой представления плана и файлов зависали или не загружались после простоя сеанса.

### Visual Studio Code - 1.137
- Автоматизация (предварительная версия) позволяет планировать повторяющиеся задачи агента на каждый час, день или неделю, а также запускать их по требованию.
- Экспериментальный голосовой режим поддерживает разговор с агентом и позволяет прерывать или перенаправлять его во время работы.
- В окне Agents можно просматривать сведения о задачах и запросах на вытягивание GitHub, даже если репозиторий не открыт.
- Быстрые чаты можно продолжить в рабочей области, сохранив заголовок, историю и текущий запрос сеанса.
- Агент может ставить сообщения в очередь для занятых чатов, чтобы параллельная работа продолжалась без прерывания активного ответа.

### Visual Studio 2026 - 18.9.1
- Исправлена ошибка, из-за которой окно предварительного просмотра команды Copilot нельзя было прокрутить и поэтому невозможно было разрешить или запретить действие.
- Исправлена проблема с агентом тестирования, появившаяся в Visual Studio 18.9.0.

### Visual Studio 2026 - Обновление за сентябрь 18.10.0
- Предварительная версия Bring Your Own Key позволяет использовать GitHub Copilot или поддерживаемые пользовательские развертывания моделей в режиме агента, включая Microsoft Foundry, OpenAI, Anthropic, Ollama и пользовательские конечные точки OpenAI или Ollama.
- Агент Git теперь может изучать запросы на вытягивание в Copilot Chat и открывать связанные комментарии и файлы; серверы MCP для GitHub и Azure DevOps добавляют дополнительный контекст.
