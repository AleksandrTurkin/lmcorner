### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.35
- Команда `/new` начинает новый диалог; при выделении текста в комментарии к pull request или issue теперь доступны Copy, Quote reply и Side chat.
- При достижении лимита контекста можно свернуть диалог или открыть обзор использования контекста.
- Личные инструкции Assisted approval позволяют задать, как оценивать запросы инструментов.
- На боковой панели pull request отображаются статусы проверок и ревью; для неуспешных проверок добавлена команда Autofix.

### GitHub Copilot CLI - v1.0.106
- В `copilot config` теперь можно выбрать уровень Fusion, GPT-6.1 Terra доступна аккаунтам с соответствующим доступом, а в списке моделей отображается размер контекстного окна.
- Для локальных сеансов с включенными настройками доступны инструменты управления сеансами и обращения через `@mentions`.
- Autopilot не начинает выполнять собственные рекомендации, если запрошен только анализ или проверка; при возобновлении сеанса восстанавливаются приостановленная цель и рекомендации по продолжению.

### GitHub Copilot CLI - v1.0.107
- Примечания к выпуску повторяют изменения v1.0.106; дополнительные изменения не указаны.

### GitHub Copilot CLI - v1.0.108
- Добавлены команды `/index`; управляемая общая индексация tgrep теперь включена по умолчанию для подходящих репозиториев и улучшает индексированный поиск по коду.
- Interactive Autopilot теперь ожидает ответы на запросы ввода и согласия от MCP, а не отклоняет их; настройки разрешений снова запрашивают решение при следующем запросе, а Assisted Permissions при блокировке инструмента могут попробовать другой подход.
- Copilot CLI отвечает на вопросы о своей работе по собственной документации и сообщает, когда документация не содержит ответа.
- Поддерживаемые модели применяют изменения уровня рассуждений, сделанные во время вызова инструмента, уже в следующем запросе; PDF-вложения для Grok 4.6 и 4.7 теперь передаются как ссылки на файлы вместо ошибки.
- Для пользовательских агентов показываются предупреждения об отсутствующих навыках, выбранные встроенные агенты сохраняются после обновления списка, семантический поиск находит переименованные репозитории, а управляемые плагины с настройкой defaultEnabled устанавливаются автоматически.

### Visual Studio Code - 1.145
- Сеансы удаленных агентов могут открывать предпросмотр приложений через браузер на удаленном узле и использовать размещенные там canvas, не покидая окна Agents.
- Вложенные сеансы могут использовать другой harness, чем родительский; у каждого сеанса свои модели, агенты и разрешения.
- Локальные автоматизации агентов теперь поддерживают расписания cron и пользовательские агенты рабочей области.
- Экспериментальные режимы подробности агента позволяют переключаться между обычным, компактным и подробным отображением без запуска нового чата.
- В рабочем наборе Copilot harness теперь учитываются правки в WSL, Dev Containers и SSH, включая параллельные изменения инструментов; в чат можно прикреплять файлы вне рабочей области.
- MCP-приложения могут предоставлять интерактивные инструменты, вызываемые моделью во время диалога.
