### Приветствую, человек 🤖

### GitHub Copilot App - v1.2.0
- Диктовка теперь поддерживает французский, испанский и другие языки благодаря загружаемой многоязычной голосовой модели.
- Автоматизации проектов поддерживают точные ежедневные и еженедельные расписания, а также пользовательские cron-расписания, чтобы агенты могли выполнять задачи по графику.

### GitHub Copilot App - v1.3.0
- Перед созданием issue в локальном сеансе агент теперь запрашивает подтверждение; вопросы скоординированного дочернего сеанса остаются в этом сеансе.

### GitHub Copilot App - v1.4.0
- Добавлены команды `/every` и `/schedule` для повторяющихся и разовых задач в сеансе или Project.
- Для новых сеансов можно оставить последнюю использованную модель или выбрать модель, уровень рассуждений и размер контекста; навыки в Customize сгруппированы по источникам, и ими можно управлять целыми группами.

### GitHub Copilot App - v1.4.1
- Локальные модели больше не блокируются в корпоративных и бизнес-аккаунтах.

### GitHub Copilot App - v1.4.2
- Сеансы теперь запускаются и возобновляются, если политика организации отключает Computer Use, даже когда эта функция включена в локальных настройках.

### GitHub Copilot CLI - v1.0.109
- Claude Fable 5.2 добавлена в список моделей; счетчик AI Credits теперь обновляется сразу после завершения `/compact`.
- Текст после `/init` теперь передается модели как дополнительные инструкции для создаваемого файла рекомендаций.

### GitHub Copilot CLI - v1.0.110
- Команды агента могут отвечать на запросы пароля Git, SSH и sudo в скрытом диалоговом окне, если включены экспериментальные функции.
- `/compact` теперь учитывает лимит AI Credits сеанса.

### GitHub Copilot CLI - v1.0.111
- `/usage` теперь обновляет данные о премиальных запросах; график активности учитывает запросы пользователя, а не подагентов или Autopilot.
- Доступ к моделям Copilot сохраняется при ограничении частоты запросов к аккаунту; поставленные в очередь изменения профиля маршрутизации Copilot Fusion подтверждаются до следующего запроса.

### GitHub Copilot CLI - v1.0.112
- В лимит сеанса включаются AI Credits, потраченные до возобновления, а подагенты соблюдают общий лимит сеанса.
- По умолчанию модели используют рекомендуемый размер контекста, сохраняя явные настройки; `/chronicle cost-tips` учитывает сеансы Copilot App и предлагает более дешевые модели и параметры рассуждений.

### GitHub Copilot CLI - v1.0.113
- Администраторы могут отключить встроенный Browser Use с помощью `features.browserUse`, в том числе в уже запущенных сеансах.

### Visual Studio Code - 1.146
- Режим Inbox показывает сеансы агентов, требующие внимания; необязательные встроенные действия позволяют исправить проверки или ответить на замечания ревью, не открывая сеанс.
- Сравнение моделей теперь поддерживает Copilot Fusion и может запускаться агентами; в окне Agents также появились отдельные окна чатов и управление расширениями.
- Сеансы Copilot CLI можно продолжать в VS Code с сохранением истории, модели, уровня рассуждений, режима и разрешений; Copilot harness работает и в виртуальных репозиториях.
- MCP-серверы могут предоставлять модели навыки; запросы разрешений Copilot harness стали точнее, а в песочнице можно скрывать значения переменных окружения.

### Visual Studio Code - 1.147
- Локальные запросы и продолжения для агентов можно запланировать, а черновики сохраняют собственную рабочую область, агента, модель и контекст.
- Browser Use позволяет агентам работать с браузером по умолчанию; удаленные HTML-файлы можно просматривать без копирования на локальный компьютер.
- Проверяющему разрешения можно указать, какие действия безопасны, а какие требуют подтверждения; маршрутизаторы моделей выбирают предпочтительные модели для разных задач.
- Ответы агентов могут содержать HTML-предпросмотры и встроенную визуализацию; агенты также помогают настраивать автоматизации.

### Visual Studio 2022 - 17.14.44
- Auto Model теперь выбирает доступную модель, а не повторяет ошибки, если ранее выбранная модель стала недоступна.

### Visual Studio 2026 - November Update 18.12.0
- Новый интерфейс Copilot Chat теперь используется по умолчанию для подходящих аккаунтов. Он предлагает отдельные режимы беседы и инструментов, контекст редактора, доверенные пути, несколько вкладок сеансов и агента Test.
- В AI Customization можно просматривать инструкции репозитория и организации, управлять навыками и MCP-серверами, а также настраивать модели: выбирать формат API, несколько провайдеров и искать ресурсы Microsoft Foundry.
- Copilot анализирует дампы сбоев, разрешает конфликты Git с пояснениями и группирует большие pull request с помощью созданных ИИ сводок и рекомендаций для ревью.
- Индексирование C++-кодовой базы теперь включено по умолчанию и предоставляет Copilot контекст репозитория для вопросов по C++.

### Visual Studio 2026 - 18.12.1
