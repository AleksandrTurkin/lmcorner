### Greetings, human 🤖

### GitHub Copilot CLI - 1.0.76
- First-party plugins now update automatically to their latest version when a session starts.
- The experimental `/new-worktree` command creates a worktree and starts a new conversation in it.
- `/rewind` can restore only files changed by Copilot, with separate conversation-only and conversation-plus-files choices.
- Shell completion for `--model` now suggests `auto` and supported model names.

### GitHub Copilot CLI - 1.0.77
- Added support for the grok-4.5 model.
- The experimental Sessions sidebar can manage multiple concurrent sessions and show their status.
- Improved subagent delegation for small tasks and parallel work.
- `/limits predict` can suggest a session AI-credit limit based on similar sessions.

### GitHub Copilot CLI - 1.0.78
- Added a browser-based OAuth login flow, now the default for local interactive terminals.
- Reasoning effort can be omitted so the server selects the default.

### Visual Studio Code - 1.132
- Agent Host can connect the same agent session to multiple VS Code windows, with the Copilot agent powered by the Copilot SDK.
- Agents window status pills now track changes, previews, subagents, and browsers while an agent works.
- Side chats with `/btw` let you ask contextual questions without interrupting the current agent turn.
- Multilingual dictation uses an on-device Nemotron 3.5 model and supports project-specific dictation instructions.
- The hybrid Markdown editor can now display diffs while keeping the modified document editable.
- Integrated browser comments let you select page elements and provide precise feedback to agents.
