### Greetings, human 🤖

### GitHub Copilot App - v1.1.28
- Custom agents can suggest next steps after finishing, with a prefilled, editable prompt to hand work to another agent; Auto mode now explains its model choice.

### GitHub Copilot App - v1.1.29
- Sessions started from a repository subfolder now apply that folder's instructions and skills, and coordinator progress includes all running nested agents.
- Cloud automations can again be created with repository-event triggers and schedules that run while your computer is off.

### GitHub Copilot CLI - 1.0.95
- The `--context` option now applies to new and resumed ACP sessions instead of silently falling back to the default or previously saved context tier.

### GitHub Copilot CLI - 1.0.96
- Model IDs in `/model` and `/config model` are now case-insensitive and saved in canonical form.
- Retry progress is now shown before responses recovered after transient model failures.

### GitHub Copilot CLI - 1.0.97
- Custom agents support agent-scoped declarative hooks, and discovery now covers deeply nested files and repositories with more than 100 agents.
- `/usage` now reports billed AI Credits for token-billed sessions, including after resume.

### GitHub Copilot CLI - 1.0.98
- Added support for the Gemini 4 Argon model.
- `/ask` answers can now be expanded and copied in full, and the last completed answer can be reopened with `/ask` or `/btw`.

### Visual Studio Code - 1.142
- The Copilot harness, powered by the Copilot SDK, is rolling out as the default for new sessions; Agent Host lets sessions continue in the background, and Ask is again available as a built-in read-only agent.
- Preview canvases let agents and users work together on interactive artifacts beside chat, such as planning boards.
- In the Agents window, chats can move to another folder or a new Git worktree without losing conversation history.
- The redesigned model picker separates Copilot and BYOK models and lets users adjust reasoning effort and context-window size.

### Visual Studio 2026 - October Update 18.11.0
- The Copilot SDK-based harness is rolling out as the default for new sessions, with Agent Host supporting background sessions and Ask available again as a built-in read-only agent.
- Preview canvases provide interactive artifacts that users and agents can inspect and update alongside chat.
- Chats in the Agents window can move to another folder or a new Git worktree while retaining their history.
- The redesigned model picker makes it easier to switch between Copilot and BYOK models and adjust reasoning effort and context-window size.
