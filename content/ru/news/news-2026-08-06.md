### Приветствую, человек 🤖

### GitHub Copilot CLI - 1.0.76
- Официальные плагины теперь автоматически обновляются до последней версии при запуске сеанса.
- Экспериментальная команда `/new-worktree` создаёт рабочее дерево и запускает в нём новый разговор.
- `/rewind` может восстанавливать только файлы, изменённые Copilot, с отдельным выбором для восстановления разговора или разговора вместе с файлами.
- Автодополнение `--model` теперь предлагает `auto` и поддерживаемые имена моделей.

### GitHub Copilot CLI - 1.0.77
- Добавлена поддержка модели grok-4.5.
- Экспериментальная боковая панель Sessions позволяет управлять несколькими параллельными сеансами и видеть их состояние.
- Улучшено делегирование небольших задач субагентам и параллельной работе.
- Команда `/limits predict` может предложить лимит ИИ-кредитов сеанса на основе похожих сеансов.

### GitHub Copilot CLI - 1.0.78
- Добавлен браузерный поток OAuth-аутентификации, который теперь используется по умолчанию в локальных интерактивных терминалах.
- Параметр усилия рассуждений можно не указывать, чтобы сервер выбрал значение по умолчанию.

### Visual Studio Code - 1.132
- Agent Host может подключать один сеанс агента к нескольким окнам VS Code; агент Copilot работает на базе Copilot SDK.
- Индикаторы состояния в окне Agents теперь показывают изменения, предпросмотры, субагентов и браузеры во время работы агента.
- Боковые чаты с `/btw` позволяют задавать контекстные вопросы, не прерывая текущий ход работы агента.
- Многоязычная диктовка использует локальную модель Nemotron 3.5 и поддерживает инструкции диктовки для проекта.
- Гибридный редактор Markdown теперь показывает различия, сохраняя возможность редактировать изменённый документ.
- Комментарии во встроенном браузере позволяют выбирать элементы страницы и передавать агентам точные замечания.
