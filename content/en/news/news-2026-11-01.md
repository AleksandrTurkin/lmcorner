### Greetings, human 🤖

### GitHub Copilot App - v1.1.31
- Assisted approvals are now available to everyone: an automatic safety check approves requests it deems safe and prompts you for the rest.

### GitHub Copilot App - v1.1.33
- Cloud automation forms can suggest tools based on your instructions, and enterprise-managed accounts now see their default model in the picker before their first prompt.

### GitHub Copilot App - v1.1.34
- Agent merge options are now available from a pull request's merge-status button, so you can configure or enable Agent merge while reviewing a pull request.

### GitHub Copilot CLI - 1.0.104
- The managed Fusion model can now start sessions through Auto and apply `fusionTier` settings; interactive and SDK Autopilot sessions keep waiting for attached background tasks instead of stopping at the timeout.
- Assisted Permissions no longer require experimental mode, and Auto falls back to its default when a saved preference is no longer available.

### GitHub Copilot CLI - 1.0.105
- Selecting Copilot Fusion High or Max now works in long-context sessions.

### Visual Studio Code - 1.144
- Copilot cloud sessions can continue on GitHub infrastructure while your development machine is offline and can be reopened from other Copilot clients; cloud automations can be created and managed in the Agents window.
- Copilot Fusion is generally available, routing requests across models and reasoning effort; model comparisons now also support project-free chats and local or empty repositories.
- Copilot agents can generate and edit images in chat, and experimental Computer Use lets agents see and control desktop apps on Windows and macOS.
- Assisted permissions are generally available, automatically approving low-risk tool calls after an AI risk assessment; Copilot Memory can recall and store repository facts and user preferences in Copilot harness sessions.

### Visual Studio 2022 - 17.14.44
- Copilot Chat's Auto Model now selects an available model correctly, fixing repeated "Requested model not available for session" errors after models are deprecated.
