### Greetings, human 🤖

### Visual Studio 2022 - 17.14.41
- Visual Studio no longer creates or updates `.github/copilot-instructions.md` when opening a solution.

### GitHub Copilot CLI - v1.0.86
- Custom agents can opt into repository instruction files (`AGENTS.md`, `copilot-instructions.md`, and `CLAUDE.md`) with `include-custom-instructions: true` in their frontmatter.
- Autopilot now stops after accepting task completion instead of continuing unexpectedly.

### GitHub Copilot CLI - v1.0.87
- Added user and managed startup defaults for the Auto routing tier, with strict or user-overridable organization policy.
- Enabled the rubber-duck agent for every model family and low-cost-tier session models.
- The timeline now shows live elapsed time for execution subagents.

### GitHub Copilot CLI - v1.0.88
- A custom agent's `reasoning-effort` now applies when selected; an explicit `--reasoning-effort` takes precedence, and unsupported levels are reported without being applied.
- Agents from plugins mounted with `--plugin-dir` are now available in server-mode sessions.

### GitHub Copilot App - v1.1.23
- Added a project setting and `/sandbox` command to run agent shell commands in a local sandbox restricted to the session's workspace.
- Agent descriptions now appear as tooltips in the agent picker and default-agent settings.
- If AI filtering in My Work can't turn a request into filters, you can continue in a session with the original request and repository prefilled.

### Visual Studio Code - 1.139
- Agent sessions can now run in Dev Containers on remote SSH, Tunnel, and WSL hosts, using the project's tools and dependencies.
- Large agent session lists load faster; the Agents Window adds a compact view and in-place renaming for sessions and nested chats.
- Sessions with multiple chats can show each chat in its own tab or only the active chat, while preserving open chats and conversation state.
