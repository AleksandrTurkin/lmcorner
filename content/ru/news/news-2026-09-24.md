### Приветствую, человек 🤖

### Visual Studio 2022 - 17.14.41
- Visual Studio больше не создает и не обновляет `.github/copilot-instructions.md` при открытии решения.

### GitHub Copilot CLI - v1.0.86
- Пользовательские агенты могут подключать файлы инструкций репозитория (`AGENTS.md`, `copilot-instructions.md` и `CLAUDE.md`) с помощью параметра `include-custom-instructions: true` во frontmatter.
- Автопилот теперь останавливается после принятия завершения задачи, а не продолжает работу без необходимости.

### GitHub Copilot CLI - v1.0.87
- Добавлены пользовательские и управляемые настройки запуска со значением по умолчанию для уровня маршрутизации Auto и строгой либо переопределяемой организацией политикой.
- Агент Rubber Duck теперь доступен для всех семейств моделей и моделей тарифного уровня Low-cost.
- На временной шкале теперь отображается фактическое время выполнения субагентов.

### GitHub Copilot CLI - v1.0.88
- Параметр `reasoning-effort` пользовательского агента теперь применяется при его выборе; явный `--reasoning-effort` имеет приоритет, а неподдерживаемые уровни сообщаются без применения.
- Агенты из плагинов, подключенных с помощью `--plugin-dir`, теперь доступны в сеансах серверного режима.

### GitHub Copilot App - v1.1.23
- Добавлены настройка проекта и команда `/sandbox` для запуска команд агента в локальной песочнице, ограничивающей доступ к файловой системе рабочей областью сеанса.
- Описания агентов теперь отображаются как подсказки в меню выбора агента и настройках агента по умолчанию.
- Если ИИ-фильтрация в My Work не может преобразовать запрос в фильтры, теперь можно продолжить работу в сеансе с исходным запросом и уже выбранным репозиторием.

### Visual Studio Code - 1.139
- Сеансы агентов теперь можно запускать в Dev Containers на удаленных узлах SSH, Tunnel и WSL, используя инструменты и зависимости проекта.
- Большие списки сеансов агентов загружаются быстрее; в окне Agents появились компактный вид и возможность переименовывать сеансы и вложенные чаты прямо в списке.
- Сеансы с несколькими чатами теперь можно отображать отдельными вкладками или показывать только активный чат, сохраняя открытые чаты и состояние разговоров.
