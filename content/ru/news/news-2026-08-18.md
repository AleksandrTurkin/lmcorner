### Visual Studio Code - 1.133
- Agent Host подключает один сеанс агента к нескольким окнам VS Code; агент Copilot работает на базе Copilot SDK.

- Экспериментальное окно Agents может открываться без входа в GitHub для сеансов Claude, настроенных с ключом API.
- Фиксация прокрутки удерживает соответствующий запрос вверху при просмотре длинного диалога.
- Встроенный браузер автоматически перезагружает локальные HTML-файлы после изменений агента.
