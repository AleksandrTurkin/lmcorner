### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.30
- Навыки можно устанавливать из папки, ZIP-архива, URL папки навыка на GitHub или HTTPS-ссылки на ZIP через Customize; перед записью изменений доступен этап проверки.
- В локальном сеансе можно менять модель и размер контекстного окна, пока он выполняется; инструменты теперь загружаются по требованию, сокращая контекст их описаний.
- Назначенные организацией агенты, навыки и MCP-серверы появляются в окне создания запроса сразу после установки плагина; настройки слияния агентом доступны и до включения Agent merge.

### GitHub Copilot CLI - v1.0.100
- Семантический поиск кода теперь включен по умолчанию в онлайн-сеансах; пользовательские агенты получают соответствующие инструменты через документированные псевдонимы `search`, `web` и `todo` или `github-mcp-server/web_search`.
- Проверенные навыки и плагины можно устанавливать по ссылкам GitHub, а назначенные команде плагины — из заданных командой маркетплейсов.

### GitHub Copilot CLI - v1.0.101
- Субагенты динамических рабочих процессов могут возвращать структурированный результат средствами модели; параметр `assistedApprovalInstructions` позволяет настраивать решения Assisted Permissions.
- Локальные модели и провайдеры на loopback больше не мешают Auto или сохраненной модели Copilot по умолчанию; в списке моделей также отмечена модель, заданная администратором.

### GitHub Copilot CLI - v1.0.102
- Режим prompt теперь учитывает управляемый выбор Auto, а субагенты соблюдают разрешения пользовательских агентов и MCP без повторных запросов подтверждения.
- Ответы, оборванные из-за перегрузки провайдера, теперь повторно запрашиваются с задержкой; также показываются сообщение провайдера и идентификатор запроса.

### GitHub Copilot CLI - v1.0.103
- Для GPT-5 теперь применяется заданная моделью детализация по умолчанию, если сеанс не переопределяет ее; вызовы инструментов Gemini больше не вызывают ошибки проверки схемы для nullable- и enum-полей.
- Облачные ответы сохраняют полный текст после разрыва соединения, а подсказки упоминаний через `#` обновляются после готовности клиента GitHub.

### Visual Studio Code - 1.143
- Среда Copilot на базе Copilot SDK теперь используется по умолчанию в новых сеансах; сеансы могут продолжаться в фоне через Agent Host и открываться как в редакторе, так и в окне Agents.
- В окне Agents можно параллельно запускать задачи с разными моделями, сравнивать результаты, поручать модели-судье выбрать подход и синтезировать итоговое решение.
- Экспериментальная поддержка локальных моделей Copilot позволяет запускать MAI Code 1.1 Flash на устройстве: такие ответы не расходуют AI Credits, а Auto может направлять подходящие запросы локальной модели.
- В сеансах Copilot harness в редакторе появилась функция Keep для проверки изменений агента на уровне файлов; доступные Canvas теперь можно открывать из меню нового чата.
- В предварительной версии Voice Mode можно использовать собственный ключ OpenAI и live-модель; установщик VS Code для Windows теперь также позволяет установить GitHub Copilot CLI.
