### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.20
- Сгенерированные артефакты Markdown теперь открываются на вкладке Files вместе с файлами репозитория; между источниками можно переключаться, а артефакт — добавить в репозиторий.
- Пользовательские агенты с одинаковым отображаемым именем в разных плагинах теперь различаются по плагину-владельцу.
- Пункт «Start from scratch» в меню создания сеансов и выборе проекта переименован в «Chat».
- Исправлена ошибка, из-за которой ответы облачных сеансов иногда обрывались и теряли последующий текст.

### GitHub Copilot App - v1.1.21
- Сгенерированные файлы Markdown теперь открываются на вкладке Files вместе с файлами репозитория; добавлены переключатель источников и возможность перенести артефакт в репозиторий.
- Одинаковые имена пользовательских агентов теперь дополняются названием плагина-владельца.
- Исправлена ошибка, из-за которой завершение фонового сеанса могло увести пользователя от выбранного сеанса или сетки.
- Длинные и многострочные ответы на запросы ask-user теперь сохраняются полностью и с исходными переносами строк.

### GitHub Copilot CLI - 1.0.85
- Добавлены параметры `/settings` для включения инструментов управления контекстом для агентов и субагентов.
- Добавлена поддержка модели GPT-6 Astra.
- Добавлены команды импорта сеансов и памяти в семантическом формате JSONL.
- Обнаруженные CLI агенты, предоставленные плагинами, теперь можно выбирать и запускать.
- Запуск субагентов теперь учитывает явно заданные модель, уровень рассуждений и уровень контекста из применимых глобальных инструкций и инструкций проекта.

### Visual Studio Code - 1.138
- Автоматизация теперь включена по умолчанию; автоматизации можно экспортировать и импортировать для обмена сценариями агентских задач.
- Сеансы агентов можно запускать в локальных Dev Containers с инструментами и зависимостями проекта.
- Расширенная поддержка Codex в Agent Host позволяет продолжать сеансы между ChatGPT и VS Code, переключаться между подписками Copilot и ChatGPT и использовать инструменты VS Code.
- Сеансы Agent Host теперь могут создавать запросы на вытягивание через форму с проверкой и редактированием заголовка, описания, статуса draft и параметров слияния.
- Завершенные сеансы агентов можно автоматически отмечать после слияния их запросов на вытягивание и при необходимости удалять после льготного периода.
- Единый выбор рабочей области и репозитория позволяет начинать работу агента из локальной папки, репозитория GitHub, облачного репозитория или удаленной цели.
