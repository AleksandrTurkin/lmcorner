### Greetings, human 🤖

### GitHub Copilot App - v1.1.27
- Resume an interrupted coordinator agent and its child sessions directly from the sidebar without leaving the current conversation.
- HydraFusion now shows the selected workflow and each pass's role, model, and duration.

### GitHub Copilot CLI - 1.0.92
- Background agents now accept steering messages while running; context rollovers preserve the latest prompts, and subagents continue working after GitHub credentials are replaced.
- Custom agents launched through ACP task calls now resolve and run correctly, and Canvas actions can return images to the model.
- Custom-agent model entries now keep model-bound reasoning effort only while that model is selected.

### GitHub Copilot CLI - 1.0.93
- Command sandboxing is now available to all users through `/sandbox` and `--sandbox`, with localhost and loopback hosts supported in sandbox network allowlists.
- MCP server configuration changes now apply between turns without restarting the session, and plugin skill commands remain available after enabled plugins reload.
- The model picker prioritizes GPT-6.1 Sol, GPT-6 Astra/Luna, and Claude 5.5; startup now honors `--context long_context` and reports its allowance accurately.

### GitHub Copilot CLI - 1.0.94
- Claude Haiku 5.5 is now available in model selection and `--model` completions.
- Assisted Permissions can send visible shell code to the permission judge, avoiding unnecessary manual approvals.

### Visual Studio Code - 1.141
- The Copilot harness, powered by the Copilot SDK, provides consistent agent behavior across Copilot products and lets the same agent session connect to multiple VS Code windows.
- Agent sessions can be arranged in a grid, while delegated conversations support steering, queued follow-ups, and replacing or cancelling queued messages.
- Cross-platform terminal sandboxing can limit agents' file and network access; inactive agent worktrees can be cleaned up manually or automatically.
- Local external Copilot and Codex conversations can continue in VS Code without losing context.
