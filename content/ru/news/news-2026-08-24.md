### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.11
- В режиме Autopilot Copilot теперь рекомендует режим разрешений, позволяющий продолжать работу без присмотра, если для разрешений инструментов выбран вариант Always ask.
- На панель чата добавлен пункт Plan, а действия бокового чата для вопросов во время сеанса теперь всегда видимы.

### GitHub Copilot App - v1.1.12
- Команды `/ask` и `/btw` открывают дополнительные вопросы, не прерывая текущий ответ.
- Активные сеансы агента теперь получают актуальное состояние запроса на вытягивание, вместо рассуждений на основе устаревших данных.
- Запрошенные хуком разрешения инструментов теперь всегда требуют явного подтверждения, а неудачная загрузка навыка отображается корректно.

### Visual Studio Code - 1.134
- Agent Host подключает один сеанс агента к нескольким окнам VS Code; агент Copilot работает на базе Copilot SDK.
- Чаты и чаты субагентов можно размещать рядом для сравнения результатов и наблюдения за работой.
- В окне Agents появилась временная шкала запросов: по ней можно переходить по длинным сеансам агента и просматривать изменения файлов.
- Поиск в чате охватывает весь диалог, включая ещё не отображённое содержимое.

### Visual Studio 2026 - 18.9.1
- Исправлено диалоговое окно предварительного просмотра команд Copilot, которое нельзя было прокручивать, из-за чего были недоступны действия разрешения или запрета.
- Исправлена проблема с Test Agent, появившаяся в Visual Studio 18.9.0.
