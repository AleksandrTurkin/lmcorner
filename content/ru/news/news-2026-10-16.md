### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.28
- Пользовательские агенты теперь предлагают следующие шаги после завершения работы, позволяя перейти к другому агенту с предварительно заполненным редактируемым запросом; Auto mode объясняет выбор модели.

### GitHub Copilot App - v1.1.29
- Сеансы, запущенные из подпапки репозитория, теперь используют инструкции и навыки этой папки, а прогресс координатора учитывает всех работающих вложенных агентов.
- Снова можно создавать облачные автоматизации с триггерами событий репозитория и расписаниями, которые выполняются, даже когда компьютер выключен.

### GitHub Copilot CLI - 1.0.95
- Параметр `--context` теперь применяется в новых и возобновленных сеансах ACP вместо незаметной подмены уровнем контекста по умолчанию или сохраненным ранее.

### GitHub Copilot CLI - 1.0.96
- Идентификаторы моделей в `/model` и `/config model` теперь не зависят от регистра и сохраняются в каноническом виде.
- Перед восстановлением ответа после временного сбоя модели теперь отображается ход повторной попытки.

### GitHub Copilot CLI - 1.0.97
- Пользовательские агенты поддерживают декларативные хуки, привязанные к агенту; поиск теперь находит вложенные файлы и репозитории, содержащие более 100 агентов.
- Команда `/usage` теперь показывает оплаченные AI Credits для сеансов с оплатой по токенам, в том числе после возобновления.

### GitHub Copilot CLI - 1.0.98
- Добавлена поддержка модели Gemini 4 Argon.
- Ответы `/ask` теперь можно развернуть и скопировать целиком, а последний завершенный ответ — открыть повторно с помощью `/ask` или `/btw`.

### Visual Studio Code - 1.142
- Copilot harness на базе Copilot SDK постепенно становится средой по умолчанию для новых сеансов; Agent Host позволяет продолжать работу сеансов в фоне, а Ask снова доступен как встроенный агент только для чтения.
- В предварительной версии Canvas пользователи могут вместе с агентами работать с интерактивными материалами рядом с чатом, например с досками планирования.
- В окне Agents можно переносить чаты в другую папку или новое рабочее дерево Git, сохраняя историю разговора.
- В обновленном меню моделей Copilot и BYOK разделены по вкладкам; также можно настраивать уровень рассуждений и размер контекстного окна.

### Visual Studio 2026 - October Update 18.11.0
- Среда Copilot на базе Copilot SDK постепенно становится вариантом по умолчанию для новых сеансов; Agent Host поддерживает фоновые сеансы, а Ask снова доступен как встроенный агент только для чтения.
- Предварительная версия Canvas позволяет пользователям и агентам просматривать и изменять интерактивные материалы рядом с чатом.
- Чаты в окне Agents можно переносить в другую папку или новое рабочее дерево Git, сохраняя их историю.
- Обновленное меню моделей упрощает переключение между Copilot и BYOK и настройку уровня рассуждений и размера контекстного окна.
