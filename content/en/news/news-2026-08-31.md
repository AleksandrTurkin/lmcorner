### Greetings, human 🤖

### GitHub Copilot App - v1.1.13
- Customize is now available to everyone, combining management for plugins, skills, MCP servers, and canvases and allowing users to create, edit, and remove personal skills.
- Pull request overviews now show and let you edit closing issues, and you can link pull requests to issues from the header menu.
- Session automations are now enabled by default, so scheduled prompts run without requiring a separate opt-in.

### GitHub Copilot App - v1.1.14
- Model, reasoning-effort, and context-window selection are now combined into one menu in the message composer.
- Agent Merge no longer incorrectly treats pull request reviews as fully resolved after checking only the first page of review comments.
- Skill load failures now appear as neutral, dismissible notices instead of replacing the skills list.

### GitHub Copilot CLI - 1.0.81
- The plugins dashboard is now available to everyone for managing plugins, skills, and MCP servers, with installed resources offering upstream updates.
- Added MCP 2026-07-28 support across the CLI, SDK, IDE, and in-memory clients.
- Added xhigh reasoning effort support for Grok 4.6 and support for Gemini 3.7 Flash.
- Startup can restore sessions that were still open when the CLI exited, and `copilot app` opens the GitHub Copilot app in the current directory.
- Added `defaultMode` and `defaultPermissionMode` settings for new interactive sessions, while Auto mode now adapts model selection as a task evolves.
- ACP clients now receive subagent IDs and live title, mode, command, and plan updates.

### GitHub Copilot CLI - 1.0.82
- Ctrl+E expands the plan approval card to show the complete plan again.

### Visual Studio Code - 1.135
- Continue recent Copilot or Claude agent sessions created in other applications directly from the VS Code Sessions list.
- Agent Host connects the same agent session to multiple VS Code windows, with the Copilot agent powered by the Copilot SDK.
- Experimental Rubber Duck provides a second opinion from a complementary model to surface missed details and edge cases.
- The Agents window now uses a streamlined side layout with simpler session controls and clearer changes, pull requests, issues, browser, and artifact status.
- Chat response footers show per-model input, cached-input, and output token usage for each turn.
