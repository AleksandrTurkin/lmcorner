### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.31
- Assisted approvals теперь доступны всем: автоматическая проверка безопасности подтверждает запросы, которые считает безопасными, а для остальных запрашивает подтверждение.

### GitHub Copilot App - v1.1.33
- В формах облачной автоматизации появилась кнопка Suggest tools, предлагающая инструменты на основе инструкций; для корпоративных аккаунтов управляемая модель по умолчанию теперь отображается в списке до первого запроса.

### GitHub Copilot App - v1.1.34
- Параметры Agent merge теперь доступны из индикатора статуса слияния в pull request, что позволяет настроить или включить Agent merge при проверке запроса.

### GitHub Copilot CLI - 1.0.104
- Управляемая модель `fusion` теперь запускает сеансы через Auto и применяет настройки `fusionTier`; интерактивные сеансы и сеансы Autopilot через SDK продолжают ждать подключенные фоновые задачи вместо остановки по тайм-ауту.
- Assisted Permissions теперь доступны без экспериментального режима, а Auto использует модель по умолчанию, если сохраненный вариант больше недоступен.

### GitHub Copilot CLI - 1.0.105
- Выбор Copilot Fusion High или Max теперь работает и в сеансах с длинным контекстом.

### Visual Studio Code - 1.144
- Облачные сеансы Copilot продолжаются на инфраструктуре GitHub, даже когда компьютер разработчика выключен, и доступны из других клиентов Copilot; облачными автоматизациями можно управлять в окне Agents.
- Copilot Fusion стал общедоступен и выбирает модели и уровень рассуждений для запроса; сравнение моделей теперь работает также в чатах без проекта и в локальных или пустых репозиториях.
- Агенты Copilot могут создавать и редактировать изображения в чате, а экспериментальная функция Computer Use позволяет им видеть приложения и управлять ими в Windows и macOS.
- Assisted permissions стали общедоступны: после оценки риска ИИ автоматически выполняются вызовы инструментов с низким риском; Copilot Memory в сеансах Copilot harness сохраняет сведения о репозитории и пользовательские предпочтения.

### Visual Studio 2022 - 17.14.44
- Auto Model в Copilot Chat теперь корректно выбирает доступную модель; исправлена повторяющаяся ошибка «Запрошенная модель недоступна для сеанса» после вывода некоторых моделей из эксплуатации.
