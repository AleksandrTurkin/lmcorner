### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.27
- Прерванного координатора и его дочерние сеансы теперь можно возобновить прямо из боковой панели, не покидая текущий разговор.
- В HydraFusion теперь отображаются выбранный рабочий процесс, роль и модель каждого этапа, а также его длительность.

### GitHub Copilot CLI - 1.0.92
- Во время работы фонового агента ему теперь можно отправлять уточнения; при сжатии контекста сохраняются последние запросы, а дочерние агенты продолжают работу после замены учетных данных GitHub.
- Пользовательские агенты, запущенные через задачи ACP, теперь корректно определяются и выполняются; действия Canvas могут возвращать изображения модели.
- Для пользовательских моделей теперь сохраняется заданный для модели уровень рассуждений только пока выбрана эта модель.

### GitHub Copilot CLI - 1.0.93
- Песочница команд теперь доступна всем пользователям через `/sandbox` и `--sandbox`; списки разрешенных сетевых адресов в песочнице теперь поддерживают localhost и loopback.
- Изменения конфигурации MCP-серверов применяются между ходами без перезапуска сеанса, а команды навыков плагинов остаются доступны после перезагрузки включенных плагинов.
- В списке моделей теперь приоритетно отображаются GPT-6.1 Sol, GPT-6 Astra/Luna и Claude 5.5; при запуске учитывается `--context long_context`, а доступный объем контекста отображается точно.

### GitHub Copilot CLI - 1.0.94
- Claude Haiku 5.5 теперь доступна в выборе моделей и автодополнении параметра `--model`.
- Assisted Permissions теперь может передавать видимый код shell на проверку, избавляя от ненужного запроса на ручное подтверждение.

### Visual Studio Code - 1.141
- Copilot harness на базе Copilot SDK обеспечивает единообразную работу агентов во всех продуктах Copilot и позволяет подключаться к одному сеансу агента из нескольких окон VS Code.
- Сеансы агентов можно расположить в сетке; в делегированных разговорах теперь можно корректировать работу агента, ставить последующие запросы в очередь, заменять их и отменять.
- Терминальная песочница на Windows, macOS и Linux может ограничивать доступ агентов к файлам и сети; неактивные рабочие деревья агентов можно очищать вручную или автоматически.
- Локальные внешние разговоры с Copilot и Codex теперь можно продолжить в VS Code без потери контекста.
