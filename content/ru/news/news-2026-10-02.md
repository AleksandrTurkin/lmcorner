### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.24
- Повторно запустить любой ответ агента теперь можно с другой моделью, уровнем рассуждений или размером контекстного окна.
- Голосовая диктовка больше не является экспериментальной и теперь включена по умолчанию; агент может ответить в существующем треде проверки pull request, не разрешая его.
- Можно искать и повторно использовать предыдущие запросы во всех сеансах.

### GitHub Copilot App - v1.1.26
- Чаты теперь могут запускать вложенные дочерние чаты со своей стенограммой, уведомлениями и планом на проверку.
- Фрагменты Bash и PowerShell из разговора можно запускать прямо в терминале сеанса; файлы можно перетаскивать на сеанс или агента в боковой панели.
- Настраивать разрешения инструментов теперь можно прямо в меню режима композитора.

### GitHub Copilot CLI - v1.0.89
- Добавлена поддержка файлов `.claude/rules` от Claude Code в качестве пользовательских инструкций; Auto теперь предлагает уровень маршрутизации, который можно изменить сочетанием клавиш или щелчком мыши.
- В список моделей добавлены GPT-6 Sol, GPT-6 Luna и Claude Opus 5.5.
- Команды агента в песочнице теперь могут обращаться к файлам и журналам сеанса.

### GitHub Copilot CLI - v1.0.90
- В меню выбора моделей добавлена GPT-6.1 Sol.
- Автоматическое подтверждение теперь учитывает сообщения, введенные во время работы агента; при сжатии контекста также формируется сводка, даже если инструкции требуют использовать инструменты.

### GitHub Copilot CLI - v1.0.91
- Добавлены команды песочницы для управления доверием к прокси-сертификатам, в том числе для автоматической настройки в Windows без участия пользователя.
- Статически анализируемые конвейеры команд только для чтения теперь могут проходить проверку доказательств выполнения; для неполных конвейеров и конвейеров без привязки по-прежнему требуется явное подтверждение.
- Команды в песочнице теперь работают в версиях Windows без поддержки перечисления файловой системы.

### Visual Studio Code - 1.140
- Copilot harness обеспечивает единообразную работу агентов во всех продуктах Copilot и позволяет подключаться к одному сеансу агента из нескольких окон VS Code.
- HydraFusion (исследовательская предварительная версия) подбирает рабочий процесс и модели для каждой задачи: например, может выбрать более мощную модель или попросить другую модель проверить и доработать результат.
- Экспериментальные сеансы с несколькими папками позволяют чатам в одном сеансе агента работать с разными репозиториями или рабочими деревьями.
- Агенты могут делегировать задачи подключенным удаленным узлам, проверять состояние их сеансов и отправлять им последующие задачи или передавать результаты исходному чату.
- Корпоративные настройки позволяют применять обязательные требования и значения по умолчанию для версий ИИ в организации.
