### Приветствую, человек 🤖

### GitHub Copilot CLI - 1.0.79
- Средство выбора моделей теперь группирует модели по разделам «Недавние», «Рекомендуемые», «Новые» и другим; сочетание Shift+Tab переключает представления.
- Добавлена поддержка модели kimi-k3.
- `--plan` теперь можно объединять с `--mode autopilot`, чтобы сначала составить план, а затем реализовать его без ожидания подтверждения.
- Плагины Agent Plugins могут поставлять расширения в каталоге `com.github.copilot/extensions/`, а пользовательские агенты учитывают отложенную загрузку инструментов.
- Вкладка и боковая панель Sessions позволяют управлять несколькими параллельными сеансами, а навигация `/tasks` поддерживает вложенный просмотр задач и интерактивную временную шкалу.
- Команда `/model` теперь по умолчанию действует только в текущем сеансе, а `/config model` задаёт значения для будущих сеансов.
- Команда `/app` открывает текущий сеанс в настольном приложении GitHub Copilot.

### Visual Studio 2022 - 17.14.38
- Исправлена ошибка запроса Copilot Chat, вызванная обращением к освобождённому объекту службы.

### Visual Studio 2026 - August Update 18.9.0
- Для поддерживаемых моделей появились уровни усилия рассуждений: низкий, средний и высокий, чтобы балансировать качество ответов и расход токенов.
- Git-агент может проверять незакоммиченные изменения и коммиты, показывая комментарии Copilot непосредственно в редакторе.
- Владельцы организации могут публиковать пользовательских агентов для всей организации; Visual Studio показывает их в средстве выбора агентов.
- Использование плана Copilot доступно прямо из окна контекста, а уведомления о приближении лимитов стали понятнее.
- Обновлённые средства выбора и управления моделями позволяют закреплять избранные модели, сворачивать остальные и просматривать стоимость, возможности и размеры контекстного окна.
