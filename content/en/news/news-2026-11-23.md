### Greetings, human 🤖

### GitHub Copilot App - v1.2.0
- Dictation now supports French, Spanish, and other languages through a downloadable multilingual voice model.
- Project automations support precise daily and weekly schedules and custom cron schedules, so agents can run recurring work at set times.

### GitHub Copilot App - v1.3.0
- Agents now ask for approval before creating GitHub issues in local sessions, and questions from coordinated child sessions stay with the child session.

### GitHub Copilot App - v1.4.0
- Added `/every` and `/schedule` commands for recurring or one-time work in a session or Project.
- New sessions can use the most recently used model or a preferred model, reasoning effort, and context tier; skills in Customize are grouped by source and can be enabled or disabled as a group.

### GitHub Copilot App - v1.4.1
- Local models are no longer blocked in enterprise and business accounts.

### GitHub Copilot App - v1.4.2
- Sessions can now start or resume when organization policy disables Computer Use, even if it is enabled in local settings.

### GitHub Copilot CLI - v1.0.109
- Added Claude Fable 5.2 to the model picker; AI credits now refresh as soon as `/compact` finishes.
- Text supplied after `/init` now reaches the model as extra guidance for the generated instructions file.

### GitHub Copilot CLI - v1.0.110
- Agent commands can answer Git, SSH, and sudo password prompts in a masked dialog when experimental features are enabled.
- `/compact` now respects the session AI-credit limit.

### GitHub Copilot CLI - v1.0.111
- `/usage` now refreshes premium-request usage and its activity graph counts user prompts rather than subagent or Autopilot prompts.
- Copilot model access is preserved when account lookups are rate-limited, and queued Copilot Fusion routing-profile changes are acknowledged before the next prompt.

### GitHub Copilot CLI - v1.0.112
- Resumed sessions count previously used AI credits toward their limit, and subagents respect the session-wide AI-credit limit.
- Models now use their recommended context window by default while preserving explicit choices; `/chronicle cost-tips` includes Copilot App sessions and recommends lower-cost models and reasoning settings.

### GitHub Copilot CLI - v1.0.113
- Administrators can disable built-in Browser Use with `features.browserUse`, including in running sessions.

### Visual Studio Code - 1.146
- Inbox mode surfaces agent sessions needing attention, while optional inline actions can fix failed checks or address review comments without opening a session.
- Model comparisons now support Copilot Fusion and can be run by agents; chat windows and extension management are also available in the Agents window.
- Copilot CLI sessions can continue in VS Code with their history, model, reasoning effort, mode, and permissions; the Copilot harness also works in virtual repositories.
- MCP servers can provide skills to the model, and Copilot harness permission prompts are more granular with optional environment-variable masking in the sandbox.

### Visual Studio Code - 1.147
- Local agent requests and follow-ups can be scheduled for later, and multiple unsent drafts can retain their own workspace, agent, model, and context.
- Browser Use lets agents work with the default browser, and remote HTML files can be previewed without copying them locally.
- Assisted-permission reviewers can follow user instructions about safe or approval-required actions; model routers can select preferred models for different kinds of work.
- Agent responses can show HTML previews and native visuals, and agents can guide automation setup.

### Visual Studio 2022 - 17.14.44
- Auto Model now selects an available model instead of repeatedly failing when a previously selected model is deprecated.
