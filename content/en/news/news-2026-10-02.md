### GitHub Copilot App - v1.1.24
- Retry any agent response with a different model, reasoning effort, or context tier.
- Voice dictation is now enabled by default, and agents can reply in an existing inline pull request review thread without resolving it.
- Search and reuse previous prompts across all sessions.

### GitHub Copilot App - v1.1.26
- Chats can now start nested child chats with their own transcript, notifications, and plan review.
- Run Bash and PowerShell snippets from a conversation directly in the session terminal, and attach files to a session or Agent by dragging them into the sidebar.
- Set tool permissions directly from the composer's mode menu.

### GitHub Copilot CLI - v1.0.89
- Added Claude Code `.claude/rules` files as custom instructions, and Auto now suggests a routing tier that you can change with a shortcut or click.
- Added GPT-6 Sol, GPT-6 Luna, and Claude Opus 5.5 to the model options.
- Agent shell commands in sandboxed sessions can now access session files and logs.

### GitHub Copilot CLI - v1.0.90
- Added GPT-6.1 Sol to the model picker.
- Auto-approval now accounts for messages entered while the agent is working, and context compaction returns a summary even when instructions request tool use.

### GitHub Copilot CLI - v1.0.91
- Added sandbox commands to manage proxy certificate trust, including unattended Windows setup.
- Statically analyzable read-only shell pipelines can now enter execution-evidence review; incomplete or unbound pipelines still require explicit approval.
- Sandboxed commands now work on Windows versions without filesystem-enumeration support.

### Visual Studio Code - 1.140
- The Copilot harness brings consistent agent behavior across Copilot products and lets the same agent session connect to multiple VS Code windows.
- HydraFusion (Research Preview) can choose a model workflow for each coding task, including escalating to a stronger model or asking another model to critique and revise the result.
- Experimental multi-folder sessions let chats in one agent session work across separate repositories or worktrees.
- Agents can delegate tasks to connected remote agent hosts, check their status, and send follow-up work or results back to the originating chat.
