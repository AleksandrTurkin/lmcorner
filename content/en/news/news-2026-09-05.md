### Greetings, human 🤖

### GitHub Copilot App - v1.1.15
- Added a `/goal` command for setting a persistent objective for autopilot in local sessions.
- Code review agents can now use a configurable reasoning effort alongside the selected model.
- Agents can create new top-level sessions directly, instead of always nesting them under the current session.
- File editing and whole-file diffs now work in WSL, Direct, and Mission Control workspaces with conflict detection.

### GitHub Copilot CLI - 1.0.83
- Custom agents can define an ordered list of fallback models, with `model-policy: required` restricting changes to that list.
- Added support for the claude-fable-5.1 model.
- MCP tools remain callable after MCP server restarts.
- Follow-up prompts entered while autopilot is running no longer disappear from the timeline.

### Visual Studio Code - 1.136
- Agent Merge (Preview) can resolve review feedback, failed checks, and merge conflicts until a pull request is ready to merge.
- Copilot and Claude agent sessions now support multi-root workspaces in the editor window.
- The redesigned new-session input combines the prompt, model, workspace, and other session controls in one layout.
- Related delegated chats and sessions now appear in a hierarchy with titles, statuses, and pending approvals.
- Agent Host connects the same agent session to multiple VS Code windows, with the Copilot agent powered by the Copilot SDK.
