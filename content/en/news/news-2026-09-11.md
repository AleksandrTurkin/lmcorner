### GitHub Copilot App - v1.1.17
- The Goal pill now shows live status and expands to display the objective, completion summary, pause reason, turn count, and AI Credits usage.
- Sessions created from projects and standalone work now share one session creation and navigation experience.

### GitHub Copilot App - v1.1.18
- Pull request fix buttons now offer a "Fix with instructions" option for adding guidance before the fix runs.
- Auto model picker descriptions now clarify the Efficiency, Balance, and Intelligence tiers.
- Fixed Agency mode and related opt-in settings sometimes remaining disabled after being enabled.

### GitHub Copilot App - v1.1.19
- Fixed the plan and files views getting stuck or failing to load after a session was idle for a while.

### Visual Studio Code - 1.137
- Automations (Preview) can schedule recurring agent tasks hourly, daily, or weekly, or run them on demand.

- Agents can queue messages for busy chats so parallel work continues without interrupting an active response.
