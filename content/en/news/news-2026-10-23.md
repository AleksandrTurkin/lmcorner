### Greetings, human 🤖

### GitHub Copilot App - v1.1.30
- Skills can be installed from a folder, ZIP, GitHub skill-folder URL, or HTTPS ZIP link through Customize, with a review step before changes are written.
- Change the model or context size while a local session is running; tools now load on demand to reduce the context used by tool definitions.
- Organization-required agents, skills, and MCP servers appear in the composer as soon as their plugin installs; agent-merge settings are available even before enabling Agent merge.

### GitHub Copilot CLI - v1.0.100
- Semantic code search is now enabled by default in online sessions; custom agents receive matching tools through the documented `search`, `web`, and `todo` aliases or `github-mcp-server/web_search`.
- Verified skills and plugins can be installed from GitHub links, and team-assigned plugins can be installed from team-defined marketplaces.

### GitHub Copilot CLI - v1.0.101
- Dynamic workflow subagents can return native structured output on supported models, and `assistedApprovalInstructions` lets you guide Assisted Permissions decisions.
- Local and loopback models no longer block Auto or the saved/default Copilot model; the model picker also identifies the administrator-managed default.

### GitHub Copilot CLI - v1.0.102
- Prompt mode now honors managed Auto model selection, while subagents follow custom-agent and MCP approvals without duplicate prompts.
- Replies cut off by provider overload now retry with backoff and include the provider message and request ID.

### GitHub Copilot CLI - v1.0.103
- GPT-5 model-specific default verbosity now applies unless the session overrides it, and Gemini tool calls avoid schema-validation errors for nullable and enum fields.
- Cloud replies retain their full text after a dropped connection, and hash-mention suggestions refresh when the GitHub client becomes ready.

### Visual Studio Code - 1.143
- The Copilot SDK-based harness is now the default for new sessions; Copilot sessions can continue in the background through Agent Host and be accessed from the editor or Agents window.
- The Agents window can run tasks with multiple models in parallel, compare their results, optionally ask a Judge model to recommend an approach, and synthesize the selected solution.
- Experimental on-device Copilot support can run MAI Code 1.1 Flash locally; those responses do not use AI credits, and Auto can route suitable requests to the local model.
- Copilot harness sessions in the editor now support file-level Keep for reviewing agent edits, and available canvases can be opened from the new-chat menu.
- Voice Mode Preview can use your own OpenAI API key and live model, and the Windows VS Code installer can now install GitHub Copilot CLI.
