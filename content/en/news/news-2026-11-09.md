### Greetings, human 🤖

### GitHub Copilot App - v1.1.35
- `/new` starts a fresh conversation; selecting text in a pull request or issue comment now offers Copy, Quote reply, and Side chat.
- Context-limit errors now offer actions to compact the conversation or review context usage.
- Personal instructions for Assisted approval let users guide how tool requests are judged.
- The pull request sidebar shows review and check progress and adds Autofix for failed checks.

### GitHub Copilot CLI - v1.0.106
- `copilot config` now supports Fusion tier settings, GPT-6.1 Terra is available to eligible accounts, and the model picker shows context-window sizes.
- Opt-in session-management tools and `@mentions` are available for opted-in local sessions.
- Autopilot respects review-only or analysis-only requests instead of implementing its own recommendations, and restores saved goals and continuation guidance when resuming.

### GitHub Copilot CLI - v1.0.107
- The release notes repeat the changes listed for v1.0.106; no additional changes are listed.

### GitHub Copilot CLI - v1.0.108
- New `/index` commands and managed shared tgrep indexing, enabled by default for eligible repositories, improve indexed code search.
- Interactive Autopilot now waits for MCP input and consent responses instead of declining them; permission defaults ask again on the next prompt, and Assisted Permissions can try another approach when a tool is blocked.
- Copilot CLI can answer questions about its behavior from its own documentation and clearly say when the docs don't cover an answer.
- Supported models apply reasoning-effort changes made during a tool call to the next request; PDF attachments for Grok 4.6 and 4.7 now fall back to file references instead of failing.
- Custom agent setups warn about missing skills, selected built-in agents stay selected after refresh, semantic code search finds renamed repositories, and managed default-enabled plugins install automatically.

### Visual Studio Code - 1.145
- Remote agent sessions can preview apps through the remote host's browser and use canvases hosted on that host without leaving the Agents window.
- Nested sessions can use a different agent harness from their parent, with independent models, agents, and permissions.
- Local agent automations now support custom cron schedules and workspace custom agents.
- Experimental agent-verbosity modes let users switch between conversation-focused, compact, and detailed views without starting a new chat.
- The Copilot harness working set handles edits in WSL, Dev Containers, and SSH workspaces, including parallel tool edits; chat can also attach files from outside the workspace.
- MCP apps can provide interactive tools for models to call during a conversation.
