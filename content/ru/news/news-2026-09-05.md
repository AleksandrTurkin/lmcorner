### Приветствую, человек 🤖

### GitHub Copilot App - v1.1.15
- Добавлена команда `/goal` для задания постоянной цели режиму autopilot в локальных сеансах.
- Для агентов проверки кода теперь можно настраивать уровень рассуждений вместе с выбранной моделью.
- Агенты теперь могут создавать новые сеансы верхнего уровня, не вкладывая их всегда в текущий сеанс.
- Редактирование файлов и изменения всего файла теперь работают в рабочих областях WSL, Direct и Mission Control с обнаружением конфликтов.

### GitHub Copilot CLI - 1.0.83
- Пользовательские агенты могут задавать упорядоченный список резервных моделей, а `model-policy: required` ограничивает смену модели этим списком.
- Добавлена поддержка модели claude-fable-5.1.
- Инструменты MCP остаются доступными после перезапуска MCP-серверов.
- Дополнительные запросы, введенные во время работы autopilot, больше не исчезают из временной шкалы.

### Visual Studio Code - 1.136
- Agent Merge (предварительная версия) устраняет замечания проверки, сбои проверок и конфликты слияния, пока запрос на вытягивание не будет готов к слиянию.
- Сеансы агентов Copilot и Claude теперь поддерживают рабочие области с несколькими корневыми папками в окне редактора.
- Обновленное поле нового сеанса объединяет запрос, модель, рабочую область и другие параметры сеанса в одном интерфейсе.
- Связанные делегированные чаты и сеансы теперь отображаются в иерархии с заголовками, статусами и ожидающими подтверждениями.
- Agent Host подключает один сеанс агента к нескольким окнам VS Code; агент Copilot работает на базе Copilot SDK.
