### Greetings, human 🤖

### GitHub Copilot App - v1.1.11
- Autopilot mode now recommends a permission mode that lets Copilot keep working unattended when tool permissions are set to Always ask.
- Added a Plan option to the chat panel, and side-chat actions stay visible for questions during a session.

### GitHub Copilot App - v1.1.12
- `/ask` and `/btw` open side questions without interrupting the current response.
- Active agent sessions now pick up the latest pull request state instead of reasoning from stale information.
- Hook-requested tool approvals now always require explicit approval, and failed skill loads are reported accurately.

### Visual Studio Code - 1.134
- Agent Host connects the same agent session to multiple VS Code windows, with the Copilot agent powered by the Copilot SDK.
- Chats and subagent chats can be arranged side by side for comparing results and monitoring work.
- The Agents window adds a prompt timeline that lets you jump through long agent sessions and review file changes.
- Find in chat searches the complete conversation, including content that is not currently rendered.

### Visual Studio 2026 - 18.9.1
- Fixed a Copilot Command preview dialog that could not be scrolled, blocking allow or deny actions.
- Fixed the Test Agent issue introduced in Visual Studio 18.9.0.
